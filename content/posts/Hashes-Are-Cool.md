What are hashes? A hash is an array of linked lists! If you are thinking what are linked lists, go check out my previous post!

So basically a hash is an array of those linked lists. Each linked list is just a part of the array. So like many linked lists.

Each element inside the list generally contains to a pointer, which all then link their respective linked lists.

Hashes might come in handy when you have like almost infinite number of elements, and you might need to narrow down the results. You can use hashes for searching, like google has almost infinite amount of data, but it still responses within a specific amount of time. They are just using hashing.
